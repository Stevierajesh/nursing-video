What changed from the script

  • Pharmacy send → decision recorded. The only "pharmacy" string in the codebase is a migration comment saying these records are not transmitted to one.
  • Re-paging every 2 min → widens to every prescriber. Nothing re-notifies on an interval; status changes once, at the SLA deadline.
  • Push/text/phone → waiting in Salus. No provider SDK anywhere; DoctorRisk.tsx says this in its own copy.
  • 1–10 concern scale → five levels. Not worried → Very worried.
  • "Both exceed 8" → nurse and vitals must agree. The real rule lives in reaches_physician().

Two clinical corrections — both confirmed by the running app

  • SpO₂ holds steady. The authored circulatory_decline scenario moves HR +40, RR +8, systolic −44, diastolic −22 and leaves SpO₂ alone. The live capture 14 minutes into the arc shows exactly that: HR 129, RR 26, systolic 75 — SpO₂ still 96%.
  • Second assessment lands at 5/10, not 6. RISK_BANDS puts amber at 4–5 and orange at 6–7, so 5/10 is what preserves the script's green → yellow → red arc.

Two bugs found while shooting

  • WorryTap.tsx:284 shows the wrong unit. It renders me?.unit?.name — the signed-in nurse's unit — beside the patient's room, so Room 609 was captioned "4 West — Med/Surg". It should read the patient's unit. Worked around in data for the shoot; the fix is one line.
  • Timmy's simulation was stranded. last_sample_elapsed sat 60,791s ahead of elapsed_seconds, which blocks the monotonic guard and makes a patient go silent — the exact failure HANDOFF.md describes. Reset as part of the setup.
